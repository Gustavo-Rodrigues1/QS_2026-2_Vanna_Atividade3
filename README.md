## Ficha Inicial do Projeto

- **Aplicação Avaliada:** [Vanna](https://github.com/vanna-ai/vanna) (`vanna-ai/vanna`)
- **Organização:** Vanna.AI
- **Licença:** MIT License
- **Versão de Referência:** Vanna v2.0.2
- **Data de Acesso:** 13/10/2026
- **Finalidade:** Framework open-source baseado em RAG e LLMs para converter perguntas em linguagem natural em consultas SQL executáveis.
- **Domínio:** Text-to-SQL, Business Intelligence e análise de bancos de dados relacionais.
- **Fluxo Avaliado:** Pergunta em linguagem natural → recuperação de contexto → geração SQL → execução SQL → resposta textual.
